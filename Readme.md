# Academy Portal 🎓

A simple and responsive **Academy Portal landing page** built using **HTML and CSS**.

## 📌 About the Project

This project is a frontend practice project designed to create a clean and responsive academy website interface.

It includes a navigation bar, search box, academy introduction section, login form, and responsive layout for smaller screens.

## ✨ Features

- Responsive design
- Navigation bar
- Search box UI
- Academy introduction section
- Login form UI
- Hover effects
- Responsive layout using CSS Media Queries
- Clean and simple user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Media Queries

## 📂 Project Structure

```text
academy-portal/
```

## 🚀 How to Run

1. Clone this repository.
2. Open the project folder.
3. Open `academy1.html` in your browser.

No additional installation is required.

## 📚 Purpose

This project was created to practice HTML and CSS concepts such as page structure, styling, Flexbox, forms, navigation, and responsive web design.
